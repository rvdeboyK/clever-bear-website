# Clever Bear Technical Consulting — Branded Website

Static GitHub Pages website for cleverbeartechnical.com.

## Deploy
Upload **all files and the assets folder** to the root of the existing `clever-bear-website` repository on the `main` branch, replacing matching files. Keep the existing GitHub Pages configuration and CNAME file.

## Important
- Contact form continues to use Formspree endpoint `https://formspree.io/f/xoeepbbp`.
- Custom domain stays `cleverbeartechnical.com` (CNAME file included).
- No GoDaddy DNS or Google Workspace MX changes required.
- Verify HTTPS and send a new test submission after deployment.
- The bear-head logo is derived from the provided logo artwork; original supplied logo is in assets.
